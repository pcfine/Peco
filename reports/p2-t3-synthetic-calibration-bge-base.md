## small vs base 对照

| 指标 | bge-small-zh-v1.5 (512d) | bge-base-zh-v1.5 (768d) |
|---|---|---|
| 正例 cosine min / mean / max | 0.7488 / 0.8872 / 0.9745 | 0.7401 / 0.8850 / 0.9750 |
| 负例 cosine min / mean / max | 0.4809 / 0.7139 / 0.9166 | 0.5229 / 0.6730 / 0.8793 |
| `min_cluster_cos`（F1 最优） | **0.77** | **0.79** |
| — 该点 P / R / F1 | 0.750 / 0.962 / **0.843** | 0.873 / 0.906 / **0.889** |
| `dedup_cos`（P ≥ 0.98 最小阈值） | **0.92** | **0.88** |
| — 该点 P / R | 1.000 / 0.321 | 1.000 / 0.585 |

**两模型判定不一致对数：13 / 113（11.5%）**（同一对在一侧 cosine ≥ 各自 F1 阈值、另一侧 < 的粗算）。
其中**负例 10 对**（small 判为重复、base 正确排除，如 `N1-08` small 0.8074 / base 0.6505）、
**正例 3 对**（base 判为重复、small 漏掉，如 `P5-08` small 0.8370 / base 0.7441 — 该对在两侧都低于/接近阈值）。

**结论**：base 在同集上全面优于 small — F1 最优 +0.046（0.843 → 0.889），
且两类分布重叠更小（正例 min 0.7401 对负例 max 0.8793 之间仍重叠，但负例均值低 0.041）。
硬删除操作点的收益最大：同为 precision 1.000 时 recall 从 0.321 提到 0.585（近翻倍），
即 `dedup_cos` 可从 0.92 降到 0.88 而不牺牲精度。代价是 768 维向量（存储 +50%）
与 base 权重加载（~389 MB，走 user-defined ONNX 路径，首次需 HF 缓存）。
是否升级取决于存储/加载成本预算 — 单看标定集质量，base 值得升级。
